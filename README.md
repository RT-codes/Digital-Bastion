# Digital Bastion — Tower Defense Prototype

A compact Unity tower-defense prototype showcasing a grid-based pathfinding system, tower placement workflow with preview visuals, and wave-based enemy spawning. Designed as a portfolio piece to demonstrate gameplay systems engineering, AI + pathfinding, editor tooling, and UX-focused features.

Why this project

- Focused: small, well-scoped prototype that implements production-relevant systems (pathfinding, placement, wave management).
- Demonstrates practical Unity skills: C# architecture, A* style pathfinding, reservation-based movement to avoid agent collisions, placement preview & editor UX, and simple wave scaling.
- Includes a UX improvement: game time automatically slows while placing towers to reduce accidental mistakes.

Highlights / features

- GridManager + GridNode: grid generation, walkability sampling, pathfinding with reservation penalties.
- Enemy + EnemyWaveManager + AI_Manager: enemy pathing, smooth movement, active-enemy tracking and wave progression.
- Build_Manager + Player_Manager + Tower: placement preview, snapping, footprint-aware validation, and confirmed instantiation.
- Placement time-slow: configurable inspector flags to reduce Time.timeScale during placement (keeps physics stable by adjusting Time.fixedDeltaTime).
- Simple UI and editor readme integration for in-editor guidance.

How it works (brief)

- A grid of GridNode prefabs is generated by GridManager. Nodes are marked walkable/blocked based on colliders tagged as "Obstacle".
- Enemies request paths from GridManager and reserve nodes as they move to avoid collisions. Pathfinding factors in reservation penalties to favour alternate routes when nodes are occupied.
- Build_Manager handles placement preview: it instantiates a preview copy, applies transparent preview materials, snaps the position to the grid, checks footprints for availability, and reserves nodes while previewing.
- When placement starts, Time.timeScale is reduced (configurable via inspector) and restored when placement ends.

Getting started (developer)

1. Install Unity Editor matching ProjectSettings/ProjectVersion.txt (Editor: 6000.4.7f1).
2. Open the project folder in Unity Hub.
3. Open `Assets/Scenes/SampleScene.unity` and press Play.
4. To test placement time-slow: trigger placement via the UI (or call `Player_Manager.RequestStartPlacement` with a tower prefab). While placing, game time will run at `placementTimeScale` (default 0.2).

Key files

- Assets/Scripts/GridManager.cs, GridNode.cs — grid generation and pathfinding.
- Assets/Scripts/Enemy.cs, EnemyWaveManager.cs, AI_Manager.cs — enemy movement and wave spawning.
- Assets/Scripts/Build_Manager.cs, Player_Manager.cs, Tower.cs — placement and tower footprint logic. (Note: Build_Manager contains the newly added placement time-slow feature.)
- Assets/Scenes/SampleScene.unity — demo scene.
- Packages/manifest.json — project packages (URP, Input System, Visual Scripting, etc.)
